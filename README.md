# 🚀 EthVim - 开箱即用的 Vim 开发环境
一键部署高颜值、高效率的 Vim 集成开发环境，支持 C/C++/Python/Java 等语言，自动补全、语法检查、文件树、状态栏、编译运行一体化。

## ✨ 特性
- 一键全自动安装，无需手动配置
- 现代化主题（gruvbox）+ 彩虹括号
- NERDTree 文件树（;n 呼出）
- Taglist 函数大纲（;m 呼出）
- Coc.nvim 智能补全（内置 Node.js 依赖）
- F2 一键编译运行 C/C++/Python/Java
- F5 快速打开终端
– F6 临时Markdown终端预览
- 自动保存 + 语法检查
- 新建文件自动生成文件头注释
